# R19_CHARGE_SUPERCAP — 窗口上下橫排磁吸／自由落座修正版

## 本版識別

`R19_WINDOW_END_ROWS_FREE_GLASS_SEAT`。charge-adg706 電容版，含K1。

- **上下蓋兩個列印件，整片上蓋可垂直取下。**
- **窗口上、下各四組磁鐵，整體84mm寬，沒有側凸磁鐵耳。**
- **取消下窗口高起內緣的玻璃承靠。** 下蓋玻璃艙槽是開底側向定位，玻璃下方不設落座階梯。
- PCB總厚按**1.6mm**；FTO先自然接觸斑馬條，閉蓋後兩條長壓腳才施壓。
- 舊側耳版已否決；其參數、工具及列印包封存於`history/R19_SIDE_EARS_REJECTED.zip`。

| 項目 | 本版 |

| 主體厚／最大厚 | 24.6／29.6mm |

| 四個X位置 | 11.9、29.2、46.6、63.9，對稱於玻璃中心X37.9 |
| 上排／前端 | 固定端Y1.1、上蓋端Y0.6 |

| 每對磁鐵面距 | **兩排均2.05mm**；各鏡像錯位0.5mm |

下排固定磁鐵位於e-paper前緣PCB下方，上蓋磁鐵位於該PCB上方。固定橋與該PCB底面名義間隙0.25mm，上蓋磁鐵座與PCB頂面間隙0.2mm；**PCB不作壓合止擋，也不被列印件夾住**。磁力穿過PCB的前緣區，磁鐵座避開e-paper顯示玻璃。

為使上下排磁路幾何一致，上排也採2.05mm磁距與反向0.5mm錯位。**這比舊版0.4mm磁距大，吸力會改變；目前沒有磁鐵牌號、拉力或斑馬條反力實測，不能把幾何對稱寫成已實測均壓。** 本版用現有磁鐵試裝確認能否保持閉合與接觸。

## 玻璃、斑馬條與剖面

- 上片：**66×60×1.6或70×60×1.6mm**；下片：置中60×60×1.6mm。
- 上片側向艙槽70.4×60.4mm；66mm玻璃由60mm下片的四角定位導正，不靠加寬上片槽自行找中心。
- 玻璃組中心X37.9／Y−33；向左1.1mm避開JP201，沿用原焊盤與PCB開窗。
- 每側一條5×50×3mm斑馬條，X2.7…7.7／68.1…73.1、Y−58…−8。
- 上蓋兩條平底壓腳**3.2×50mm**，每條接觸面160mm²，底面Z4.3。

| 剖面基準 | 自由落座 | 名義閉蓋 |
|---|---:|---:|
| PCB背面 | −1.6 | −1.6 |
| 完成焊盤頂面／斑馬條底面 | 0 | 0 |
| 下片玻璃底面 | 1.4 | 1.1 |
| 上片FTO接觸面／斑馬條頂面 | **3.0** | 2.7 |
| 上片玻璃頂面 | 4.6 | 4.3 |

PCB的1.6mm是總厚包絡，完成接觸銅面為Z0，35µm銅色示意層包含在包絡內。自由落座時，上片電極帶與斑馬條相接；閉合壓縮目標0.3mm／10%。**不再以舊下窗內緣限制玻璃高度。** 外殼自身閉合定位面只限制蓋的位置，不先從下方頂住玻璃。

使用者最新實物觀察是FTO離斑馬條約0.2mm。本次以此取代先前「已接觸」的判斷。CAD另檢查下片投影下方無塑膠，以及66mm上片自由狀態與兩側條各有140mm²名義接觸；此為幾何結果，尚不是新印件的實測接觸電阻。

下殼透光口61×61mm，PCB原開窗約57.918mm；54×54mm有效光路保持暢通。側壁及定位角只在玻璃外側，不做底部承托。

## 咬合與一次性裝板

保留原R18定位唇截面：舌寬1.4、高2mm、名義0.2mm配合；沒有新增強倒扣。空殼輕咬合作定位，窗口磁鐵與長壓腳負責壓合。

為把下排磁鐵收在窗口旁，PCB從後端入口裝入，上蓋本身同時關閉此入口。**這是一次性裝板路徑，不影響日常整蓋取下換玻璃。**

1. 上蓋、玻璃、斑馬條及PCB螺絲先移開。
2. 完整PCB在最終位置後方71.2mm，保持水平、Z+1mm，先降至入口高度。
3. 水平向前推71.2mm，通過下蓋定位壁及下排橋下方；到孔位後再降低1mm，PCB背面落在Z−1.6承靠上。
4. 固定PCB，再裝斑馬條與DSSC。玻璃先靠定位壁自由落在斑馬條上，再垂直蓋上整片上蓋。

電容版兩條底部避空槽延伸至後端，以容納已焊好電容的裝板路徑。前兩顆PCB螺絲M3×8、後兩顆M3×14，均低頭（頭徑≤5.5、高≤2mm）；後螺帽從底面凹槽放入，固定後不突出殼底。

K1維持B.Cu正確旋轉與八腳位置；局部底面Z−8.2、底厚1.4mm，名義淨空1.02mm。
USB-C金屬面至U腔內端面0.58mm，已保留接點突出與上蓋拆卸空間。一體按鈕功能區與R16來源相同。

## 重建工具

使用FreeCAD附帶Python，依序執行`tools/build.py`、`tools/check.py`、`tools/check_board.py`、`tools/thickness.py`、`tools/export.py`；再用Blender背景模式執行`tools/blender.py`，重新開啟blend以同腳本加`-- --verify`檢查，最後以FreeCAD Python執行`tools/release.py`。

本地來源足以重建，不依賴R18或另一個R19資料夾。`--bootstrap`只供重新擷取工作區來源。尺寸記錄在`parameters.json`，主要幾何構造在`build.py`。
